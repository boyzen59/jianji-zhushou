# jianji-zhushou

历史视频剪辑助手 Skill 3.4，用于素材编排、真人露脸录制包、分镜动效、播放问题回修和中文审阅交接。

## 使用

将本仓库放入 Codex 的 skills 目录，例如 `~/.codex/skills/jianji-zhushou/`。在新任务中调用 `$jian-ji-zhu-shou-2-0`。入口为 [SKILL.md](SKILL.md)，按任务读取 references，不需要加载所有文档。

支持已有图片、AI视频、真人录像及SRT时间定位；可生成完整朗读文案、原声精确切片和前置3秒倒计时录制版。以用户最新要求为准，区分计划、静态审阅、真实动画和成片验收。项目案例保留制作规则，个人文件和本机目录不包含在仓库中。
