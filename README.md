## 使用

将本仓库放入 Codex 的 skills 目录，例如 `~/.codex/skills/jianji-zhushou/`。在新任务中调用 `$jian-ji-zhu-shou-2-0`。入口为 [SKILL.md](SKILL.md)，按任务读取 references，不需要加载所有文档。

支持中文文案、时间戳、图片、AI视频和真人录像。新分镜明确原句、参考机制、动作时序、相机、素材可见区间及前后镜接力。旧视觉与图片运动规则作为可选参考。保留真人录制切片、音轨、审阅与续跑能力。入口链接到经过核实的参考索引、动效配方、Remotion生产规则和可运行原创组件包；只有实际渲染通过才称效果已实现。

制作计划开工前检查Shotcraft及其他参考缓存、实际Skill路径和拟用插件；缺项必须先向用户提醒用途、影响与补齐方式，不能静默跳过。按用户补齐或明确允许继续的回应推进。
