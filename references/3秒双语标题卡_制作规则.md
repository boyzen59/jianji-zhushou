# 固定2秒双语章节过渡卡

文件名中的“3秒”仅保留旧路径兼容，实际总长2.0秒（60fps为120帧）。它替代旧1.5秒章间间隔，不叠加额外空白；卡内不放正文口播，按需要可有独立键盘打字音效。guide的3秒静音和蜂鸣不进入章卡。

内容为真实章节标题的中英配对，可有中文章节序号与极少要点。更多章节要点交给后续解释镜头，不堆进2秒；无装饰类别、时长、内部章节码或其下划线，详见SKILL.md。

- 0–约0.35秒：羊皮纸/衔接背景与淡黑透明卡建立。
- 约0.35–1.15秒：中英文标题依层级建立。
- 约1.15–1.40秒：可选短要点建立。
- 约1.40–2.00秒：稳定落定；审阅帧选文字完整、退场前的帧。

遵守[视觉材质](visual-style.md)。同一固定组件可跨不同章节边界复用，是普通相邻动效不重复规则的例外；每个边界只播一次，不连续堆叠章卡。大章与首小章同边界不重复过渡；大章10秒全屏＋5秒小窗从卡结束计时。
