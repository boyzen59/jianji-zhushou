# 从参考到 Remotion 的动效配方

这是可扩展的机制库，不是白名单或轮换表。先按[首要参考索引](motion-reference-index.md)选择与文案相符的案例。下列是针对本工作流的设计归纳；标记“基础组件”的代码随Skill提供，其余需要按项目实现，不能宣称已自动具备。

| 机制 | 适合文案 | 画面动作和素材衔接 | Remotion实施与注意点 |
|---|---|---|---|
| 对象跨镜接力 | 前因后果、同一事物的变化 | 图中物件成为符号，符号成为节点，再进入下一幅素材；构图保留连续身份 | 基础组件SharedElement：插值位置/大小/角度/圆角；两侧共用对象ID、global frame与交接状态，不卸载重置 |
| 素材卡到全景 | 从多个证据聚焦一个事件 | 前后景卡错峰进入，选中卡向镜头扩展成为下一段全屏素材 | 基础组件MediaCard+SharedElement；图片/视频是内容插槽，透视、阴影随深度变化。不是每镜强制卡片 |
| 证据内部揭示 | 图像细节支撑论点 | 先建立全图，局部圈注/遮罩显露，放大细节，退回整体或延伸成下一场景 | SVG mask/clipPath+独立overlay，基于原图坐标；读史料时镜头可静止，不能臆造史料文字 |
| 路线与关系生长 | 贸易、迁徙、战争路径、制度关系 | 主体节点触发线条延伸，抵达节点后再出解释，终点变下一镜焦点 | 基础组件TracePath；pathLength=1，dashoffset由frame求值；真实地理要有数据，抽象关系图标示意 |
| 数量实体化 | 有依据的数量/积累/倍数 | 文稿提到多少就出现多少物件，归组或聚合为真实结果；焦点切到解释 | 自行用稳定ID排列与错峰；多到不可数时改明确单位分组。无数值不画伪统计，禁从示例挪数据 |
| 图表转叙事空间 | 同口径趋势、对照、结构 | 同一组数据先建立，再强调差异，保留轴/对象身份进入下一解释 | SVG点/轴/面积由真实数据求值；计数和读数落点同步，量纲、区间和来源不丢失 |
| 纸本拼贴与撕边 | 史料、人物、观点冲突 | 人像/史料纸片错层入场，圈注带动观察，撕口或纸边揭出后镜 | 基础组件TornMatte+MediaCard；边缘固定seed、纸芯与阴影分层。参考口播Word、huashu和vox-explainer |
| 手绘图解 | 机制、轻松类比、关系建立 | 先画主线、再分叉和箭头，重点词落定；线条转换成下镜引导 | TracePath+分笔SVG；boil可按时间量化后seed采样，30fps的3帧节奏改按0.1秒，不机械照搬到60fps |
| 绘画/水墨揭示 | 时代意象、气氛、艺术史 | 笔触先构成空间，再显露主体和细节，墨迹遮罩带出下一景 | 预生成笔触事件表，当前frame重新求可见笔触。不能用依赖上一帧的累积画布；历史照片仍与重建区分 |
| 单色光场收束 | 开场、关键揭晓、情绪转折 | 光场和定向拖影引出主体，阅读前收束；将前景色域接入下一素材 | 基础组件MonochromeLight负责单色光影；真正运动模糊另用官方组件并检验版本，不把CSS blur称为快门模糊 |
| 字形成为空间 | 关键词、年份、重要转折 | 大字轮廓作窗口，内部露出图片；拉近窗口进入场景，字退出阅读角色 | SVG文字mask或本地字体路径；避免中文缺字、轮廓裁切。整句字幕不是主动画替代品 |
| 同轴对照 | 前后/两方同维度比较 | 保留共有参照，改变比较对象；分隔线或共用主体完成交换 | 全局layout anchor与mask；图表尺度不随镜头偷偷改变。无数量时用定性并列 |
| 纵深时间走廊 | 历史阶段和连续演化 | 年份/事件处在连续空间，镜头到达当前事件，前一阶段退居后景 | CSS perspective或@remotion/three；真实年份与叙事顺序对应。深度布局不暗示不存在的精确时间比例 |
| 3D拆层或剖面 | 机构构成、结构机制、物件内部 | 结构按解释顺序拆开，视线沿关系移动，重组或转接下一场景 | @remotion/three统一frame，材质/灯光/相机记录；仅有平面照片不能假称真实物理结构 |
| 真人参与图解 | 叙事引入、观点、因果讲解 | 人像全屏/侧栏/局部与图形相互让位；从所指对象切入证据 | 独立真人轨和全局媒体时间；位置按实际面部与手势安排，不强制圆窗和比例 |

## 每个配方的落地要求

3.1新增可运行示例位于`assets/remotion-kit/src/style-directions.tsx`：
- Lemo灯台观察方法 → FocusLens：同一源图坐标复制与裁切，放大不改变证据。
- MG形变方法 → morphContour：相同顶点数与顺序的轮廓插值，检查中间态是否自交。
- Shotcraft空间镜头方法 → DepthDirection：分层深度与统一相机变换；仍是2.5D，不宣称真实3D。

Dashi／Huashu用于将原句变为可见动作与材料语法，Wtt用于主体身份和事件时序，xilo用于方向比较。这是方法适配，不是已移植全部上游组件。

写明来源文件、触发原句、动作的起末状态、持续对象、关键帧、空间路径、参考速度/材质如何改编，以及代码组件。0.1秒错峰或3%回弹只是可调整参数，不是所有片的标准答案。

一个亮点可以由多个协同层构成，但同时争夺注意力的主体要收敛。冲击动作后须让证据看清。辉光、粒子、撕纸、色差、景深不是禁止项，也不默认全加；采用理由必须能联系到本句的情绪或含义。

来自其他引擎的参考先移植为纯frame函数，完成随机帧检查与连续试片再入片。记录原参考与本次真实实现差异，不能把“类似效果”写成1:1复现。
