# 执行交接与恢复

交接MD给新窗口提供可直接使用的任务入口，包含：

- 当前授权阶段、锁定的批准版、素材/文案/音频绝对路径、数据优先级；旧版本明确标为参考，不能与当前指令叠加。
- 全量媒体逐条表：真实文件、正文依据、REV、源入出点、局部/全片时基、有效可见区间及状态。文件名编号只是线索；旧候选列表不等于已入片。
- 动效主配方、实际源码及主题适配范围。可复用组件与待实现组件分开标注；只写效果名不算实现，静态PDF不算动画。
- 当前可运行入口、锁定依赖、分段范围、检查点和失败处理。示例入口若只渲染样片，明确全片尚需接入哪些数据。

按时长和设备资源分批，用户指定十段时按十段；一次只跑一个生产段，帧并发从已验证值开始，避免多个浏览器拖死机器。GPU编码与浏览器/滤镜计算分开记录，支持GPU不等于全部处理走GPU。

源WAV、当前SRT、旧审阅时码建立明确映射后再生产；局部帧与全片帧不能混用。每段边界按同一绝对时基量化，跨段转场保留handle后精确裁切。

已完成段按输入/配置/代码指纹复用，只让受影响段失效。路径或解码失败使相应段失败，不输出空白替代，不删除其余进度。实际渲染图层导出的使用表与库存对账，区分已分配、已渲染可见、用户已批准。

需要工具时先查现有scripts的--help；缺库才运行bootstrap_motion_libraries.py，存在性自检不代表模块可编译或素材已覆盖。只在用户要求制作成片时进入渲染。
