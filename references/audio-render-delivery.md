# 真人、声音与成片

## 出镜与录制包

出镜方式遵循[制作默认值](production-defaults.md)或项目覆盖。先核对录像、台词及源剪点；按完整语义选段，缺素材标待录，其余工作继续。收窗发生在句中时保留连续原声，形态变化沿同一源时钟，不重播录像。同步素材不以头像、循环或其他台词替代。

完整前期包的录制项包含：需求ID、REV／章节、选段理由、完整连续台词、源录音起止、目标露脸范围、录制时长。以SRT和实际语音校准，在句段边界切片，保留停顿；额外录制余量不计成片露脸时间。

- exact：原声精确切片，供正常时间线使用。
- guide：严格3.00秒前导，在0、1、2秒各播放提示音（默认880Hz、0.15秒），第3秒接同一exact；仅供录制准备，不进入成片。
- reading：每段完整台词TXT，与exact、guide使用相同需求ID。
- 总包：全部台词、逐段TXT、exact、guide、清单和露脸时间表。已合格资料复用；缺录音／时码明确未完成项，不重新配音冒充原声。

检查guide时长=exact+3.00秒；提示音仅在前导，之后与exact一致。格式不变时用PCM样本核对。脚本：`scripts/build_presenter_audio.py`，参数`--output-dir`、`--ffmpeg`。输入示例：

~~~json
{
  "source_audio": "long-narration.wav",
  "segments": [{
    "id": "REC-001", "review_id": "REV-0001", "scene_id": "S0001", "chapter": "CH01",
    "start": 12.0, "end": 27.0, "narration_zh": "实际完整台词",
    "presenter_arrangement_zh": "本段出镜方式与收窗终点",
    "selection_reason_zh": "引入本章核心问题",
    "target_range_zh": "母版上实际起止时间"
  }]
}
~~~

start/end是原录音时码，不是添加过转场的成片时码。可切音频并不证明台词及关联字段齐全。

## 时基与音轨

匹配原录音时，以WAV样本数／时长为权威。章卡和转场使用既有时间预算，保留原停顿；明确要求改变音轨才增加间隔，并记录源→成片时码映射。仅裁用户确认的非正文前导，不继承其他项目裁切量。章卡见[章节规则](3秒双语标题卡_制作规则.md)，回跳排查见[播放连续性](playback-continuity.md)。

旁白、AI视频原声、音乐／音效分轨。主画面AI片段默认静音；需要其原声时单独输出全片对齐48kHz WAV及清单。真人原声用于同步或指定旁白替换，避免同句双人声。无合适音乐可省略。

`scripts/build_ai_video_audio_stem.py`按clips计划处理源入点、时长与成片入点。明确无音轨可补静音，缺源或探测失败报错；脚本不支持playbackRate，确有变速先生成对应派生音频。长路径／大量输入按连续时间块处理，跨块调整源入点、块内归零，同格式拼接；所有音轨对齐相同终点，不把旧stem套到新时间线。

## 交付与恢复

按项目规格交带声视频或静音编辑母版，分轨按需；逐句字幕及外置SRT状态跟随项目策略。

仅当用户要求静音编辑母版且未另定规格时：MP4、H.264 High、2560×1440、60fps CFR、yuv420p、Rec.709、无音频／字幕流。这是编辑规格，不是额外插入静音时段。

`build_render_plan.py`为就绪spec建计划，默认不覆盖已有进度；确需重建才用`--overwrite`并保留备份。按[交接规则](execution-handoff.md)复用检查点和片段，数据变化仅使相关段失效。实际入口不存在时先实现，不交虚构续跑命令。
