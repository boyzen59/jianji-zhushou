# 真人、声音与成片

## 出镜与已有录像

3.0默认开头0–15秒全屏真人，配按文案设计的浮动关键词/标题；15秒后由导演选合适完整段落作右下小窗，与视频、图片和图解并存。形状、比例和过渡由构图决定，不恢复旧10秒开头、固定圆窗、10%–20%配额或只在章节开头出现的限制。用户若明确另有安排则记录覆盖项；不能因“自由导演”遗漏开场或后续小窗。

先核对录像、台词及源内剪点。出镜段按完整意义组织，不能拿头像、循环录像或不同台词冒充同步；缺素材列待录，其余已授权制作继续。录制区间可长于实际露脸窗口，以完整句段交台词；15秒若落在句中，保留连续录制，以同一源时钟收为小窗或接B-roll，不硬切原声。真人轨与文字轨分离，形态变化不重播源视频。右下小窗放在字幕安全区上方，脸部避让标题、证据和图例。

## 录制需求包

前期默认附完整真人录制包，不因用户只审文字而省略。仅当用户明确该片不出镜或本次仅修改规则/个别交付时不重建录制包。按选中的出镜段落从长录音切片，不重新合成语音替代。每项包含需求ID、REV/章节、选择理由、完整连续朗读文案、源录音与源起止、目标出镜范围和录制时长；文案不是标题或碎句列表。按SRT与实际语音匹配，在完整句段边界裁切，保留原句间停顿，前后录制余量另记、不计入成片露脸比例：
- exact：原声精确切片，不添加引导，适合正常时间线。
- guide：严格3.00秒倒计时前导，在0、1、2秒各播放一次短提示音（默认880Hz、0.15秒，表示3、2、1），第3.00秒衔接同一exact原声切片；不是先静音3秒再加蜂鸣。guide只供录制准备，不进入成片或露脸占比。
- reading：每段独立的完整朗读文案TXT，另交总录制清单；文案、exact与guide使用同一需求ID配对。
- 已给且符合要求的录制/切片复用；缺长录音或时码时明确缺项，不冒称切片已完成。

总交付至少含全部完整台词、逐段TXT、exact音频、guide音频、录制清单及露脸时间表。核对guide时长=exact+3.00秒，提示音只在前导段，guide第3秒之后与exact一致；若采样格式不变，用PCM样本验证源片段。倒计时不进入正式视频。保持原WAV/SRT，字幕关闭不影响切片与定位。

脚本入口：scripts/build_presenter_audio.py，参数--output-dir与--ffmpeg。计划示例：

~~~json
{
  "source_audio": "long-narration.wav",
  "segments": [{
    "id": "REC-001", "review_id": "REV-0001", "scene_id": "S0001", "chapter": "CH01",
    "start": 12.0, "end": 27.0, "narration_zh": "实际需要录制的中文台词",
    "presenter_arrangement_zh": "按项目批准的出镜时段与收窗终点",
    "selection_reason_zh": "本章以新的核心问题引入，适合真人说明",
    "target_range_zh": "填写母版上真实出镜起止时间"
  }]
}
~~~

start/end用原长录音时码，不能用加过过渡的成片时码。旧计划缺文稿/关联字段即使能切片，也不是完整录制需求包；补齐实际字段再交付。

## 时基与声音分轨

进入实际播放实现或排查收窗回跳、视频冻结时，读取[播放连续性](playback-continuity.md)，按独立媒体/真人/文字轨处理；不要沿用文字页的局部时间重置源视频。

用户要求匹配原录音时，以原WAV样本数与时长为权威，保留原文件已有静音；章卡/转场在既有画面预算内覆盖或重分配，声音连续，不擅自插静音或增加总长。仅在用户明确授权改变音轨时才新增间隔，并写入源时码→成片时码映射。只有经确认的非正文前导才裁切，不把某项目4.5秒裁切量推广。帧数统一从绝对边界计算，正常句间停顿保留。章卡详见[章节衔接规则](3秒双语标题卡_制作规则.md)。

旁白、AI视频原声、音乐/章节音效分轨。AI画面默认静音，原声单独输出全片对齐48kHz WAV与逐条清单，让用户决定是否保留。计划记录源入点、时长、成片入点；明确无音轨可补静音，缺源/探测失败必须报错，不能混为“无声”。真人原声用于同步或指定旁白替换，不和同一句配音重叠成人声双轨。

scripts/build_ai_video_audio_stem.py按clips计划工作；不支持playbackRate，确有变速先生成同处理的派生素材。Windows长路径/大量输入时分连续时间块处理，跨块片段调整源入点，块内时码归零，再按相同格式顺序拼接；不要一次命令塞全片长路径。每份派生音轨对齐同一总终点，已有旧时间线stem不能直接套新片。

## 交付与恢复

前期默认交导演执行MD、素材需求、完整真人录制包、中文文字修改Word和16:9文字画面PDF；PPTX仅按用户要求。需要成片则生成带声视频或指定静音编辑母版，分轨按需交付。默认不含逐句字幕的画面与字幕流；SRT作为独立对齐资料保存。音乐无合适输入可省略，不因此阻断主任务。

仅在用户要求静音编辑母版时采用：MP4、H.264 High、2560×1440、60fps CFR、yuv420p、Rec.709、无音频流与字幕流；项目另有规格则用项目值。无音轨母版是编辑规格，不是额外前3秒静音；如另要带声音成片，按用户选择的轨混合。

build_render_plan.py只为已就绪的新spec建计划，默认拒绝覆盖已有进度；确认需要重建时才用--overwrite并保留自动备份。检查点和分段产物一起复用，数据变动只让受影响段失效；实际生产入口不存在就先实现，不交虚构续跑命令。
