# 视觉方向与验画

## 一份项目风格卡

在 `art-direction.md` 保存本片的主视觉决定，章节引用它：
- **内容与情绪**：主要论点、受众、需要记住的画面，哪些段落应安静或有冲击。
- **视觉识别特征**：选定风格最关键的可见特征，例如透光纸边、干湿墨层、错位印刷、连续轮廓；写到能对照成帧检验。
- **颜色与字体角色**：背景、正文、证据、强调色的值和用法；本机可用的中文字体、字号层级、字重及替代字体。
- **空间与材质**：主体尺度、前中后景、光源、阴影、纸／玻璃／金属等材质构成。
- **运动语言**：主动作、相机、辅助层的分工，停留与强弱变化，跨镜延续对象。
- **采用记录**：具体来源、改编点、组件和代表静帧／动态片段。

有参考图时分析实际图像的构图、笔触、颜色和空间；参考视频还分析动作与时序。只读文档时标“文档机制参考”。分析阶段全量扫描能力目录，深入阶段只读选中来源的相关原文，不要求遍读全库源码。

## 组合方法

先选表达，再选机制。模型有权按文案自由拓展，不把“用某个库”当创作目标：

| 文案需要 | 可优先尝试（不是绑定关系） |
|---|---|
| 看见人物／场景／细节 | 真实图像、史料定位、局部揭示；缺适当素材时用明确标识的重建或生成图 |
| 比较数值／趋势／结构 | 表格、条形／折线、关系图；无可靠数值时用定性图解，不编造统计 |
| 多条证据／并置观点 | 拼贴、同轴对照、局部覆盖，靠共享标记组织观看顺序 |
| 抽象因果／过程 | 对象动作、路径、形变、剖面；图解和实拍可以在同镜接力 |
| 气氛／空间想象 | GPT生成图、艺术材质、遮罩或分层视差，与全片设计参数匹配 |

需要原创位图且内置生图工具可用时，可按当前制片授权自主调用；使用可用的imagegen技能，参考已定风格与主体身份，生成后检查并落盘，再编排遮罩／运镜或分层。图中文字和数据尽量由代码排版。不要把一张平面图假称已抠出真实深度；生成重建不冒充史料。工具不可用时说明具体缺项，继续其他镜头；不擅自切到付费外部服务或索取密钥。

Lemo／Huashu负责材料、造型与时代视觉；Dashi负责把口播中的概念变成能看见的事件；MG Styles提供形变、线条、拼贴等识别特征；Shotcraft提供相机与素材进出场机制。按内容选用其中几项，不要求全用。

全片统一色彩语义、字体角色、线条尺度、材质与光向、运动曲线和对象身份；布局、媒介与强弱节奏可以自由变化。Herk的共享tokens方法帮助一致性，Prompt Motion提供具体图表／机制案例。统一不等于同版换字；从史料进入图解可延续轮廓或标记，按内容建立衔接。

## 具体质量标准

- 暂停能认出主体和论点，播放能顺着注意力理解变化；缩到手机观看尺寸仍有清楚层级。
- 重点动作发生在物体、证据和关系上。普通标题入场不能承担全部解释。
- 材质有结构和光照依据：纸边／纸芯／投影、玻璃透射、金属高光或水墨笔触；检查细线闪烁、渐变色带、颗粒和景深。
- 正文、题注、脸部、关键证据互相避让；字幕区读取项目配置。重要信息落定时减少装饰干扰。
- 史料整体保留比例，细节放大保留来源位置线索；视差只用可分离的真实区域。没有深度依据时采用平面运镜。
- 修正必须指出时间码、可见问题和处理方法。自评分可排优先级，不能用“9分”或“电影感”认证质量。

允许静止、辉光、粒子、3D、拼贴和任何合理颜色。运动频率、风格数量、缩放比例、镜长都由内容与实际预览决定；外部作者的固定配额不进入全片约束。
