# 玻璃与版式

统一淡黑透明玻璃、白字、柔和阴影；样式起点见[card.css](../assets/templates/card.css)。旧项目样式名OTTOMAN_SMOKE_LIQUID_GLASS_V1可保留兼容，不把项目名称当内容或新项目配置。

- 1080p起点：染色rgba(14,14,16,.23–.30)、模糊4–8px、饱和度120%–140%、轻微折射约1.012–1.022；随背景调整可读性，纹理仍应可辨。参数是起点，不是逐镜机械锁定。
- 无外围、内圈或顶部白色描边/环绕高光线；靠材质差异与阴影区分。主中文白色、英文略弱，橙红强调重点。字号、圆角与内边距服从内容。
- 浮动信息框优先左上，避开人脸、手势与证据。主体用用户图片/视频或羊皮纸；不以大片不透明蒙层遮住被计入覆盖的素材。
- 史料采用原比例框内大图与独立侧栏，可左右换位；重要题注/页边信息不能被玻璃遮住。无适配图片则改完整图解版式，不保留史料空框。
- 小窗位置集中在项目theme配置；用户要求向右下移时以已有坐标调整，留安全区并避开证据。具体坐标随画幅等比换算，不固定到所有项目；小窗无白环，缺真人不画空圈。
- 内容过密优先重排、改纵向栏目或分到后续镜头，不缩成难读小字。图表轴线、语义连线可保留；无数据采用等高定性栏目，不能用柱高伪装数量。

v2只吸收信息结构与视觉层级；其纯黑底、白框、零阴影、固定字重、装饰刻度和统一入场不覆盖当前风格。原素材内文字属于素材本体，不能伪造为可编辑对象；若素材自带不允许的烧录字幕，列具体裁切/处理需求，不声称仅关闭字幕组件即可去除。

字幕、标签、固定章卡与相邻动作限制统一以SKILL.md为准，不额外叠加一套模板禁令。
