# 制作默认值

这些是用户的制作偏好，不是模型能力限制。用户明确变更时记录项目覆盖项及对应原话，按新要求实施；外部参考不能自行覆盖。单次任务仅修改规则、分析参考或回修局部时，不启动完整制片流程。

| 项目 | 默认值 |
|---|---|
| 叙事与时间 | 中文稿为叙事依据，原录音为时长依据；SRT用于定位，句级时间不冒称逐词精确 |
| 画面 | 16:9，以1920×1080设计；帧率和交付分辨率按项目确认的规格 |
| AI视频 | 每条源0–10秒、正常速度、单次连续完整播放；转场在该窗口内，不循环、冻结或变速凑长 |
| 真人 | 开头0–15秒全屏并配必要浮动字；随后自主选段右下小窗，位置避让重要信息；全屏收窗沿同一源时钟 |
| 逐句字幕 | 中文、英文均关闭；SRT独立保存，成片不挂载字幕组件、不烧录或封装字幕流 |
| 字幕安全区 | 归一化x=.05、y=.82、width=.90、height=.14，可按画幅调整；重要文字、脸部、图例、证据避让，正式画面不画预留框 |
| 屏显文字 | 标题、关键词、数字、图解和史料题注可显示；每个字段有稳定ID及原句／来源依据 |
| 文字审阅 | 中文Word为用户修改入口；16:9 PDF展示真实构图中的文字位置、大小和出现模式；英文先留位，中文修订后翻译同步 |
| 前期交付 | 导演MD、素材清单、完整真人录制包、中文文字Word、16:9画面PDF；用户缩小范围时按本次范围 |
| 创作决定 | 按文案自主选择与糅合表现形式；同片共用一套风格体系，不逐镜询问或按库轮换 |
| 风格选择 | 直接交5页16:9视觉PDF供用户选择重点／提出调整；已有定稿或明确委托自主定稿时不重复等选。完整文字校对PDF不受5页限制 |
| 制作引擎 | Remotion统一动画和最终画面；FFmpeg处理媒体、音轨与编码 |

素材比例由文案决定，可自由组合AI视频、图片、史料、表格、图解与拼贴，不固定哪类必须主导。按章看实际可见覆盖。采用AI视频时，非标准10秒文件列差异；用户另有明确用法时记录覆盖，不能默默改剪。

预览不是正式媒体使用：机制样片可以使用原创示意图并标注用途；实际AI视频即使放入样片也遵循项目播放约定。样片时长不成为正式片长限制。
