# 从文案到画面

新片设计读本文件。制作参数见[默认值](production-defaults.md)，参考选择见[路由](motion-reference-index.md)。

## 先确定需要讲清什么

完整阅读稿件，以稳定句ID关联主张、证据、因果、对比和情绪。接入原声、时间戳与素材清单；没有音频可完成估时草案，精确动作落点留待复核。待生成素材按提示词判断主题、空间、年代，不预设精确手势或物体位置。

每段回答：观众已知什么、新理解是什么、依据是什么、画面中发生什么变化。已有稿件按原意设计；只有用户要编剧时才改编口播。

然后阅读完整[能力目录](motion-reference-index.md)和[内容模块](content-motion-modules.md)，不要一开始就按熟悉的库或已安装包缩窄。可运行`python scripts/query_motion_library.py --catalog`取得包括补充库的完整来源清单。在项目的`analysis-coverage.md`逐项记录source_id、适用／不适用／待核实、相关原句或段落及简短理由；同机制可成组说明，但每个来源都须被覆盖。此处是能力适配分析，不代表看过全部样片或读完全部代码。未取得的资料如实标待核实，不能伪造已参考。

分镜从“原句 → 需要新增的理解 → 适合的媒介 → 具体动作”生成。能被静止证据解释清楚时允许静止；只有无数字的概念就不强造统计图；生成图只补合适的表达，不替代真实证据。先前分析仍有效的续作或局部回修复用覆盖记录，不重扫无关部分。

## 风格体系与5页选择稿

新片借鉴xilo的比较方法，在内部探索必要的不同方向后，自主收敛为一套与文案相符的系统。用户看到的是直接可选的5页视觉PDF，而不是外部Skill目录或多套互不相干的风格拼盘。

这5页可组织为：整体体系／图像叙事／图表或机制／拼贴／生成图与跨镜扩展；具体内容随文案改变，不要求每次凑齐这五种。每页有真实构图、对应原句、动作说明及选择编号；动画卖点用2–3个关键状态表达，不把静态PDF称为动态验收。无需用户先读MD、PPT或视频。内部短试片仅按实现风险制作；全部屏显文字校对另按实际数量覆盖，不为5页遗漏正文。

共用设计参数写入`art-direction.md`及工程tokens，镜头只改编布局和动作。用户明确要先选时，在这份PDF后等待该选择；具体技术组合自主决定。已定风格、局部回修或明确委托自主定稿时直接深化，不重复选型。只有文字计划或明确不要预览时不额外渲染。

进入制作前核对：每镜有原句与解释目的；完整能力目录已分析且待核实项不会阻断所选机制；各媒介都引用同一份风格卡。检查章首、章中、章末及跨镜接力的颜色语义、字体、线条、材质光向和动作曲线。修正风格漂移后再扩展同类镜头，不能用“混合媒介”解释不一致。

## 将参考嵌入分镜

按[分镜模板](../assets/templates/video-spec-template.md)记录：

| 信息 | 要写到什么程度 |
|---|---|
| 语义与时基 | 原句ID、事实、原声／成片区间、cue精度 |
| 主体与素材 | 可辨识主体、前中后景、asset_id、到位状态、源与可见窗口 |
| 动作 | 起始构图 → 主要变化 → 阅读停留 → 结束状态；触发词、轨迹、开始／高潮／落定帧 |
| 接力 | 延续的对象／轮廓／方向／位置；出入口状态和转场窗口，必要时明确硬切 |
| 风格与实现 | 具体参考文件／版本、选取的机制、项目改编、组件路径和验证状态 |
| 文字与真人 | 屏显ID、中文及英文预留位置、真人录制需求ID与避让 |

全片或章节共用的参考记录一次并用ID引用；镜头只写差异，避免为同一个选择重复作文。查过但不采用时简述原因；无需为了通过检查虚构引用。

## 节奏与重点镜头

旁白语义决定节奏。强动作放在问题建立、关键因果、反转或结论显现处，随后留出理解时间。相机与画面主体分工：素材自身已明显运动时，减少额外机位运动；读证据时可静止。

开头和关键段落设计可记住的视觉事件，例如“账目的一行变成资源流，汇入节点后展开成空间结构”。先让对象和因果成立，再加光影、粒子、材质。不同章节可换布局、媒介和动作强弱，但不另起一套风格；任何辅助材料都先适配共享风格卡。

长片按章组织素材覆盖和复杂度。先验证最难的素材交接，再复制已验证机制到相同需求；不要把同一个卡片版式换字铺满全片。

## 完成

计划交可执行MD及本次要求的前期包；画面制作交实际预览与可继续的源码；成片任务按[制作与验收](remotion-production.md)继续到完整输出。缺项只影响相关部分，已有成果按版本复用。
