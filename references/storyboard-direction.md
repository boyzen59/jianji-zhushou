# 文案驱动的分镜导演流程

制作分镜与动效时必读。用户收录的Skill是首要设计资料，文案是最高内容依据。先查[参考索引](motion-reference-index.md)，读取与本片最近的具体案例/机制，再写分镜；不要求整体安装外部Skill。

## 理解、对齐、看素材

正式计划前先按[开工提醒](preflight-and-notices.md)检查Shotcraft、其他参考缓存及拟用插件；缺项先告知用户补齐，不能只因可原创Remotion就跳过提醒。等待补齐/明确允许继续期间可先进行原文阅读和素材盘点。

1. 完整阅读中文稿，给段落/句子稳定ID，提炼主张、证据、因果、比较、悬念、转折和落点。保留原意与论证关系。
2. 对齐SRT/VTT/JSON和原录音。句级字幕只能保证句段边界，不能按字数均分后称词级精确。重要动作词须经音频复核；缺音频记cue-level/estimated，继续完成草案。
3. 计划阶段读取文件清单、原提示词和已有元数据；尚未生成的条目标pending，不反复打开图片，也不预览生成视频模板。按大致主题、氛围、空间和年代匹配文案，不按文件顺序串片，不假定AI会实现某个精确动作。执行阶段收到素材后才检查实际动作、视线、方向、解码和构图，落实适配。
4. 写每段的“观众已有信息 → 新增理解 → 证据 → 画面里的变化”。宏大、幽默、紧张、冷静来自文案，不预设所有段落都是广告高潮。

## 让首要参考真正参与设计

每章先写“参考项目/具体文件 → 借鉴机制 → 对应句段 → 本片改编”。优先查用户给的已核实项目，内部旧库和补充搜索只填缺口。选取的是机制而非品牌、示例事实、固定镜长或作者的私有路径。

可以借鉴huashu的解释语法与材质、motion-video-kit的对象接力、motion-broll的语义落点、Klik的视线调度、Remotion官方的实现规则。查阅文件/URL、起末状态、选用理由、改编办法都写入分镜。只读了文档就记“文档机制参考”，不称看过/复现其视频。

先提出适合全文的主视觉方向并自行决定；规划时用文字描述，不默认渲染方向试片。用户要求的文字构图PDF可做静帧。执行阶段按需要试验动效，不把逐项选配色/挑特效或审分镜变成等待门槛。外部参考冲突时按文案判断，不累积为全片禁令。

## 逐镜写到可以实施

使用[分镜模板](../assets/templates/video-spec-template.md)，每镜必须说明：

- 原句/ID、源与成片区间、同步精度、必须表达的事实。
- 主体、证据、前中后景；素材ID、原提示词、生成/到位状态、真实路径（未生成为空）和有效可见区间。AI视频源0–10秒、正常速度一次播放，裁切仅指画面构图，不指截短时长。
- 叙事动词：汇合、扩张、分裂、包围、替换、显露、追踪、对比、失衡等。仅“淡入”“文字出现”不能解释设计。
- 开始构图 → 主动作 → 解释停留 → 结束状态。写触发词、开始/高潮/落定帧、轨迹、缓动和强度，文字与装饰另排时序。
- 相机如何引导视线，主/辅动作如何分工。静止可有理由，不强制所有图片漂浮/推近。
- 前后镜接力：延续哪个对象、轮廓、方向、位置或声音；出入口尺度与速度、重叠窗口。不能只写“转场0.5秒”。10秒AI视频没有额外源余量，转场算在其播放窗口内，时间并集单独计数；不强依赖未生成的动作和物体精确位置。
- reference、mechanism、adaptation、component、实现状态和所需素材。自行实现也须记录查阅过的用户参考与选择理由。
- 屏显文字ID及中文内容、英文预留区域、字幕安全区、真人全屏/右下小窗和录制需求ID。默认没有逐句口播字幕；重要文字不能占用保留区。

重点改写分镜的动效衔接，不擅自重写中文口播全文。屏显概括回溯原句，人物/事件/数字对应真实证据。

## 节奏

旁白语义是主节拍，音乐是辅助。导演语义段可以长于或短于一个视频播放窗口，10秒整段视频不等于每个镜头/文字组都必须10秒。已有口播不硬套120BPM或2秒章卡。可用0.25–0.7秒建立、0.08–0.18秒错峰、0.3–0.9秒转场作为执行起点，再依据具体句长、阅读量和动作调整。

能量沿论证起伏：建立问题、证据机制、转折揭晓、看懂结果。开头和关键反转设计视觉记忆点，不设炫技配额。强动作后留理解时间。同一母题可连续发展，但不能只换字和颜色复制卡片。

## 连续两镜示例

仅作方法示范，不能替换用户文案：“港口聚集了货物，也把税收带回都城。随后，资金又流向前线。”

镜A用实际港口视频建立空间，货物轮廓经遮罩接到图解中的物件符号，沿两条路线汇入“都城”。“聚集”触发汇合，“都城”时节点落定。没有数量依据就只画定性流动。

镜B保留同一节点与流向，拉出前线分支；“资金”触发资源符号流动，落点以形状/色彩匹配接到战场素材。借鉴motion-video-kit的对象延续和huashu的解释语法，路径、遮罩、视频和相机全部由Remotion控制。实际地理未知则明确示意，不画假疆域。

## 实施与交付

先完成全稿导演执行MD、重点衔接、素材需求和真人录制包。按章检查AI视频覆盖和图片/史料穿插，不让长解说主要靠换字卡片支撑。MD要让下一执行者无需猜测即可接入素材，分镜不等用户审批。交文字Word与16:9画面PDF让用户修正屏显内容，未校正文字标待校对。进入用户授权的执行阶段才做复杂连续试片、回修和全片；实际素材与预期不符时改编构图/补需求，不改正文与原声来迁就素材。
